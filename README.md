# Royal Chess

Веб-шахматы на Flask: бот с 5 уровнями, регистрация, личный кабинет, рейтинг, онлайн-вызовы, сохранение и продолжение партий.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:5000`.

## Railway

1. Создайте пустой GitHub-репозиторий и загрузите код.
2. В Railway создайте проект через **Deploy from GitHub repo**.
3. Добавьте сервис PostgreSQL.
4. В Variables приложения добавьте `SECRET_KEY` со случайным длинным значением.
5. Railway автоматически передаст `DATABASE_URL` от PostgreSQL, если подключить базу к сервису.
6. Команда запуска уже задана в `Procfile`.
7. Откройте **Settings → Networking → Generate Domain**.

## Что уже работает

- регистрация и вход;
- профиль и рейтинг ELO;
- статистика побед, ничьих и поражений;
- бот: новичок, лёгкий, средний, сложный, эксперт;
- проверка легальности ходов на сервере;
- онлайн-вызовы между игроками;
- обновление онлайн-партии через Socket.IO;
- автоматическое сохранение позиции после каждого хода;
- продолжение незавершённой партии позже;
- адаптивный дизайн.
